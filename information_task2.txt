    Regarding the file format choice:
I chose MessagePack (msgpack) because:

More efficient than JSON (smaller size, faster parsing)
Supports binary data
Language-agnostic format
Good compression capabilities
Maintains data types
Fast serialization/deserialization
The storage structure:

Files are organized by date: YYYY/MM/DD/
File naming: {url_hash}_{timestamp}.msgpack
Each file contains:
Document content
Original metadata
Processing timestamp
Processing version info
