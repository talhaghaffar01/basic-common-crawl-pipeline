Run the system with tokenization

Train tokenizer on sample data:

python worker.py \
    --minio-endpoint=localhost:9500 \
    --minio-access-key=minioadmin \
    --minio-secret-key=minioadmin \
    --minio-bucket=commoncrawl-data \
    --train-tokenizer \
    --min-length=500 \
    --max-length=1000000

Use a pre-trained tokenizer:

python worker.py \
    --minio-endpoint=localhost:9500 \
    --minio-access-key=minioadmin \
    --minio-secret-key=minioadmin \
    --minio-bucket=commoncrawl-data \
    --tokenizer-path=/path/to/tokenizer.json

Tokenized document includes:

	•	Original text
	•	Token IDs
	•	Token strings
	•	Attention mask
	•	Metadata & processing info
