To run the system with tokenization:
First, you might want to train the tokenizer on a sample of your data:
python worker.py \
    --minio-endpoint=localhost:9500 \
    --minio-access-key=minioadmin \
    --minio-secret-key=minioadmin \
    --minio-bucket=commoncrawl-data \
    --train-tokenizer

Or use it with a pre-trained tokenizer:
python worker.py \
    --minio-endpoint=localhost:9500 \
    --minio-access-key=minioadmin \
    --minio-secret-key=minioadmin \
    --minio-bucket=commoncrawl-data \
    --tokenizer-path=/path/to/tokenizer.json

The tokenized documents will now include:
Original text
Token IDs
Token strings
Attention mask
Metadata and processing information
